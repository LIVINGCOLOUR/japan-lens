# RSS 利用条件の調査メモ（2026-09-27）

各社の利用規約ページは直接読めなかったため、フィード内の著作権表示・検索結果・アーカイブから分かった範囲。
**公開前に各社の現行規約を人の目で確認すること。**

| 媒体 | 分かったこと | 公開サイトでの扱い |
|---|---|---|
| NYT | 個人利用と非商用ブログでの利用を認め、掲載時は所定の形式と出典表示を求める。配信停止を求める権利を留保（旧RSSページのアーカイブ。現行版は未確認） | 非商用なら範囲内の可能性。出典表示の形式を確認する |
| WSJ | フィードの著作権表示は「All rights reserved」。個人・非商用利用のみで、それ以外は Dow Jones Reprints に問い合わせるよう案内（検索結果） | 公開サイトは「個人利用」を超える可能性が高い。4社で最も確認が必要 |
| BBC | 2008年に RSS のライセンスを商用利用まで広げたとの報道あり。フィードは見出しと1文のリード（現行条件は未確認） | 条件付きで可能な可能性。現行の条件を確認する |
| CNA | 規約が見つからなかった。フィードに著作権表示なし | サイトの利用規約を確認し、必要なら問い合わせる |
